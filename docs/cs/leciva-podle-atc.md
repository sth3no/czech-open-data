# Počet léčivých přípravků v ČR podle ATC skupin

Kolik léčivých přípravků je v databázi SÚKL v každé anatomické a terapeutické skupině ATC (1. a 2. úroveň) a kolik z nich hradí zdravotní pojištění.

Databáze léčivých přípravků SÚKL obsahuje 70 032 kódů SÚKL (variant přípravku podle síly a balení), z toho 8 622 hrazených ze zdravotního pojištění.

- **Stav dat:** 1. 11. 2026
- **Řádků:** 110
- **Zdroj:** [SÚKL (Databáze léčivých přípravků)](https://opendata.sukl.cz/katalog-otevrenych-dat/databaze-lecivych-pripravku-dlp)
- **Licence:** Podmínky SÚKL, komerční užití povoleno
- **Jak citovat:** Zdroj: SÚKL (Databáze léčivých přípravků); zpracoval czechdatasets.com, https://czechdatasets.com/otevrena-data/leciva-podle-atc
- **Ke stažení:** [CSV](https://czechdatasets.com/open/leciva-podle-atc.csv) · [JSON](https://czechdatasets.com/open/leciva-podle-atc.json) · [Markdown](https://czechdatasets.com/open/leciva-podle-atc.md)
- **Stránka tabulky:** https://czechdatasets.com/otevrena-data/leciva-podle-atc
- **Plná datová sada:** [Léčivé přípravky (SÚKL)](https://czechdatasets.com/data/sukl-leciva)

Jeden kód SÚKL je jedna varianta přípravku (síla, léková forma, velikost balení), ne jeden název léku. Zahrnuje i přípravky s ukončenou registrací, které se ještě smějí doprodávat.

## Sloupce

| Sloupec | Popis |
| --- | --- |
| `atc_kod` | Kód ATC (1 písmeno = anatomická skupina, 3 znaky = terapeutická skupina) |
| `nazev` | Název skupiny |
| `nazev_en` | Název skupiny anglicky |
| `uroven` | Úroveň ATC (1 nebo 2) |
| `pripravku` | Počet přípravků (kódů SÚKL, tedy variant síly a balení) |
| `hrazenych` | Z toho hrazených ze zdravotního pojištění |
