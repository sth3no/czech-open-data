# Number of Czech data boxes (datové schránky) by type

How many data boxes (datová schránka, the Czech government e-delivery system) of legal entities and public authorities exist, by box type.

The list holds 857,866 data boxes of legal entities and public authorities, of which 17,935 belong to public authorities.

- **Data as of:** 9 November 2026
- **Rows:** 5
- **Source:** [Digital and Information Agency of the Czech Republic (list of data boxes)](https://www.datovka.gov.cz/sds/welcome?part=opendata)

Boxes of natural persons and sole traders are not included; they are not published.

## Columns

| Column | Description |
| --- | --- |
| `typ_ds` | Box type: PO = legal entity, OVM = public authority |
| `podtyp_ds` | Box subtype (Czech) |
| `pocet` | Number of data boxes |
